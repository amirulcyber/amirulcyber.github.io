{%- comment -%} One row of the writing list: thumbnail, title and date, then the post's lede. The thumbnail is the post's `thumbnail:` if it sets one, otherwise its `image:` — which is normally the link-preview card. That card is 1200x630 and has the site name on it, so at 160px wide it reads as colour rather than detail. A post that wants a legible thumbnail should set `thumbnail:` to a purpose-made crop; posts with neither simply render without one. The lede is truncated in Liquid *and* line-clamped in CSS: the markup stays small, and a browser without -webkit-line-clamp still shows a sane amount instead of the whole paragraph. Usage: {% include essay-card.html post=post %} {%- endcomment -%} {%- assign lede = include.post.description | default: include.post.excerpt -%} {%- assign thumb = include.post.thumbnail | default: include.post.image -%} {%- if thumb %} {%- endif %} {{ include.post.title | smartify }} {{ include.post.date | date: '%d %B %Y' }} {%- if lede %} {{ lede | strip_html | normalize_whitespace | truncatewords: 30 }} {%- endif %}

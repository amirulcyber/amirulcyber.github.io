{%- comment -%} One row of the writing list: thumbnail, title and date, then the post's lede. The thumbnail is the post's own `thumbnail:` front matter. It is deliberately not inferred from `image:` — _config.yml sets a site-wide default `image` (the link-preview card) on every post, so `image` is always present and inferring from it would put the brand card on posts that have no artwork of their own. A preview card is 1200x630 with the site name on it, so cropped into a 160x90 box it reads as colour rather than detail; a post that wants a legible thumbnail should point `thumbnail:` at a purpose-made crop. The lede is truncated in Liquid *and* line-clamped in CSS: the markup stays small, and a browser without -webkit-line-clamp still shows a sane amount instead of the whole paragraph. Usage: {% include essay-card.html post=post %} {%- endcomment -%} {%- assign lede = include.post.description | default: include.post.excerpt -%} {%- assign thumb = include.post.thumbnail -%} {%- if thumb %} {%- endif %} {{ include.post.title | smartify }} {{ include.post.date | date: '%d %B %Y' }} {%- if lede %} {{ lede | strip_html | normalize_whitespace | truncatewords: 30 }} {%- endif %}
